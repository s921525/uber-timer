# ⏱️ Uber 工時與跑單時間計算器

專為 Uber / 外送夥伴量身打造的工時與跑單時間記錄網頁。支援**多單並行計時（單單、雙單、三單獨立計時）**、**每日統計報表（總單數、總時長、每單耗時）**、**Excel 依日期自動分頁匯出**、以及**手機連線電腦單機使用**。

---

## 📱 手機連線電腦使用教學

電腦與手機只要連上**同一個 Wi-Fi**（或手機連上電腦開的行動熱點），手機就能直接連進來使用！

### 步驟 1：啟動本機伺服器
直接在資料夾中**連點兩下執行**：
👉 `啟動手機連線伺服器.bat`

終端機視窗開啟後，會直接顯示您電腦目前的 IP 網址（例如）：
```
=============================================================
  ⏱️  Uber 跑單時間計算器 · 手機連線伺服器已啟動！
=============================================================

💻 【電腦本機瀏覽器】請開啟：
   👉 http://localhost:3000

📱 【手機瀏覽器】請確保手機連上同一個 Wi-Fi，並輸入：
   👉 http://192.168.68.114:3000   (Wi-Fi)
=============================================================
```

### 步驟 2：手機開啟網頁
1. 打開手機的瀏覽器（Safari / Chrome）。
2. 在網址列輸入畫面上顯示的網址（例如：`http://192.168.68.114:3000`）。
3. 即可直接在手機上點擊開始接單、雙單、三單與直接結束！

> 💡 **加到手機主畫面（全螢幕 App 體驗）**：
> - **iPhone (Safari)**：點擊底部「分享」按鈕 ➔ 選擇「加入主畫面」。
> - **Android (Chrome)**：點擊右上角「⋮」選單 ➔ 選擇「加到主畫面」或「安裝應用程式」。
> 這樣手機桌面上就會有專屬圖示，點開就像原生 App 一樣全螢幕跑單！

### 步驟 3：資料自動同步到電腦
手機跑完單後，所有紀錄除了存在手機瀏覽器外，伺服器還會自動將紀錄存入電腦中的 `data/orders.json`，在電腦上隨時都能查看與匯出 Excel 報表！

## ✨ 核心特色

1. **每日單號嚴格重設**：
   - 每天第一筆跑單一律固定由「第 1 單」開始編號。
   - 誤按刪除某筆單據後，系統自動將當日剩餘單據重新整隊編排（第 1 單、第 2 單…），序號絕不跳號。

2. **一鍵直接結束**：
   - 送達時直接按「直接結束 (第 X 單)」，不跳出任何多餘彈窗，立即結算存檔。

3. **多單並行計時（疊單/夾單）**：
   - 快捷鍵：`+ 接一單`、`雙單模式`、`三單模式`、途中隨時 `+ 再接一單 (夾單)`。
   - 每筆訂單獨立計時，先送達哪單就按哪單結算。

4. **Excel 原生分頁匯出 (`.xlsx`)**：
   - 點擊「匯出 Excel (依每日分頁)」，每一天自動劃分成獨立的工作表分頁（例如：`2026-11-08`、`2026-11-07`），首頁還有「每日總覽彙整」，帳目清楚明瞭。
